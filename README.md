# Mirror Web - Professional Screen Projection Software

A modern, responsive promotional website for Mirror Web - professional screen projection software that allows users to mirror their Android screens to PC with ultra-low latency and high quality.

## 🌟 Features

### Website Features
- **Modern Design**: Sleek, professional design with dark theme and cyan accents
- **Responsive Layout**: Fully responsive design that works on all devices
- **Interactive Elements**: Smooth animations, hover effects, and interactive modals
- **Loading Animation**: Professional loading screen with spinner animation
- **Smooth Scrolling**: Smooth navigation between sections

### Promotional Content
- **Hero Section**: Eye-catching introduction with animated screen mockup
- **Feature Showcase**: 6 key features highlighting the software's capabilities
- **Download Section**: Clear call-to-action with download options
- **Interactive Modals**: 
  - Download modal with trial/pro versions
  - Demo modal with video placeholder
  - Setup guide with step-by-step instructions

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs entirely in the browser

### Installation
1. Download or clone the project files
2. Open `index.html` in your web browser
3. The website will load automatically with the loading animation

### File Structure
```
Mirror Web/
├── index.html          # Main HTML file
├── styles.css          # CSS styles and animations
├── script.js           # JavaScript functionality
└── README.md           # This documentation
```

--primary-color: #00d4ff;
--secondary-color: #0099cc;

- Change download links and system requirements
